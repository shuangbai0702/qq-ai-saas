# 03 · 纸白与正红

用户已确认保留当前视觉和交互。这里是控制台基础 UI 的独立材质样本，不接业务流程。

当前预览：<http://127.0.0.1:5173/design-lab/20261101/03-cotton/index.html>。根入口 `index.html` 同样跳转到第三套。

## 当前样本

- 白纸主按钮、小按钮、迷你按钮；面板保留裁纸边、薄纸截面、层叠和五角印点星。
- 页签用白纸选中层、正红粗字和红色短笔画区分；开关含纸片滑动与印记变化。
- 按钮、页签、开关、复选框和标签共用局部三色纸面染印，颜色在纸边内、文字下面展开，随后淡回白纸。
- 进度条拖动时给已填充轨道染色，保持拖动期间显色，松开后淡回红线；滑块保持纸白。键盘调整同样有反馈。
- 背景为浅灰画稿，圆头笔保留分束笔纹和干笔留白，鼠标经过显出原图颜色。笔迹约停留 2.6 秒，再用 3 秒淡出；密集输入不会按长度截掉先前笔迹。

## 实现入口与边界

`03-cotton/index.html` 只加载本目录的 `style.css` 和 `study.js`。`study.js` 组织 26 个生成纸面，并使用：

- `paper-renderer.js`：程序生成纤维、压纹和印点材质图，单一共享 WebGL2 渲染器；纸面固定照明，按压改变厚度与阴影；不可用时回退 Canvas 2D。
- `dry-ink.js`：纸面内短暂的细干笔触感。
- `wallpaper-paint.js`：圆笔显色、时间分层的稀疏蒙版、图像加载与释放。
- `pigment-feedback.js`：纸边内的三色染印，以及拖动轨道的染色。

所有动画由 `study.js` 的单一视觉时钟驱动。手动暂停、系统减少动态和页面隐藏停止持续运动；暂停时直接操作可以留下静态染印，恢复后继续消退。退出解除监听、断开观察器并释放图像、GPU、纸面和临时染色画布。

壁纸使用 AATINF 的 C77《成熟·办公桌场景壁纸》，原图与来源记录在 [assets/SOURCES.md](03-cotton/assets/SOURCES.md)。壁纸是外部素材，纸面材质和反馈由代码生成。运行仅加载本地素材，没有业务 API 或外部请求。旧实验文件保留为过程记录，当前入口不加载它们。`03-cotton` 是保留的旧地址名，可见设计已改为细白纸。
