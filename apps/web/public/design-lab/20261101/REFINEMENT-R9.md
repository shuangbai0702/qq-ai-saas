# 纸面基础元素 · 第九轮

## 本轮要求与原计划

用户要求在基本元素展示界面优化：折线图、普通条目悬停、输入框焦点、半透明长条及其他半透明元素、选中文本效果。保留已确认的白纸 / 正红点缀、清爽可爱、强程序化材质；按钮染印和圆形背景笔刷继续沿用。

1. 固定当前样板和正式接入版基线。修改限 `03-cotton` 展示页及本记录，不自动同步正式项目，不提交 Git。
2. 补齐当前展示页没有的折线图、普通条目、半透明长条和可选文本样本，只展示 UI 材质，不添加业务功能。
3. 折线用纸上纤维墨迹与网点；条目悬停用有纸纹的局部染印和压痕；输入焦点用铅笔压边、纸内淡彩与清楚的输入状态；半透明改为薄纸透印，文字保持实色；文本选中按真实原生选区生成破边染色。
4. 新表现统一接入已有时钟和 Owner，保留原生输入、选择、复制与键盘焦点。覆盖暂停、减少动态、滚动/缩放、隐藏、资源释放和回退；不给已有按钮和背景换效果。
5. 在实际展示页截图并验证五类效果、窄屏与生命周期，最后对照计划说明实际结果与未执行项。

基线和本轮证据位于忽略目录 `test-results/paper-refinement-20261102-r9/`。后续追加执行与 Plan vs Actual，不重写本段原计划。

## 用户补充与接入计划

- 用户以截图明确“普通条目”指平整的多列表格行，“透明长条”指宽幅原生折叠栏。第一轮新增的卡片行、叠加悬停与输入大面积染印被否定；修改为独立、克制的材质语言，保留已确认按钮效果。
- 用户允许探索留空彩印、涂鸦、字体等方式，这些是举例，不限定实现手段。当前采用连续浅拓印、铅笔压边、薄纸透景、留白套印选区；不用一套三色晕染覆盖所有元素。
- 用户指出字周围的矩形留白挡住行纹理，已删除文字矩形遮罩，拓印连续经过文字下方。
- 用户随后明确授权“可以，应用到项目里面吧”。据此扩展原计划第 1 项的范围：将本轮已确认表现迁入 `apps/web/src/paper/` 并适配真实 DOM；不提交 Git，不部署或操作真实机器人。

接入步骤：迁移原样板画笔与选区算法 → 真实表格 / 输入 / 折叠栏适配 → 根据真实 SVG 采样路径迁移墨迹与网点（保留数值、坐标与未知断点） → 原页面回归、生命周期与视觉复核 → 原计划与新增授权的 Plan vs Actual。

## 实际实现

- 样板补齐了折线图、原生多列表格、可选文字 / 多行输入以及宽幅原生折叠栏。普通行只显示一层连续浅拓印，去掉文字周围的矩形遮罩、行卡片纸层与额外描边；输入只保留纸白变化、细灰压边和很短的朱砂笔迹。
- 选中文字使用留白印边与轻微错版网点；与按钮的纸内三色染印分开。使用真实原生 Range / selectionStart / selectionEnd，不改文字、输入值、复制或业务事件；滚动容器内选区按实际裁切范围绘制。
- 正式项目增加 `paper-ink.js` / `paper-details.js`，画笔算法来自当前样板。沿用原 Runtime 的时钟、事件 Owner 与退出流程，没有新 RAF、定时器或业务请求。
- 表格只为活动行分配拓印缓存，离开后释放；图层位于文本下方。实际输入保留原生 DOM 和边界，焦点使用单个共享画布；原生 dialog 中的输入与选区画布进入其顶层，关闭后移回。
- 原生 details 的自有纸层放在 summary 内，避免被浏览器当作折叠内容隐藏；闭合是薄纸透景，展开恢复完整纸面。没有重写折叠操作。
- 实际折线图读取现有 SVG 的真实 M/L 路径，沿用原始坐标、未知断点、轴标、图例与无障碍说明。纸上墨粒与网点按 getScreenCTM 的实际投影绘制，处理宽图 SVG 的等比留白；没有把样板固定数据搬进业务。
- 已确认的按钮染印、圆形壁纸笔刷、点印星、共享材质渲染器和两份归档保留。`src/style.css`、`src/main.tsx` 与本轮前基线一致，其他业务页面代码未编辑。
