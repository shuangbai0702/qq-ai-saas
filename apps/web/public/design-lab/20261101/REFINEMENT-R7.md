## 方法调查与取舍

先把方法分开，避免把“程序化”等同于 hover 缩放、弹簧或堆叠粒子。

| 方法 | 视觉用途 | 本次取舍 |
| --- | --- | --- |
| 规则图案 / 平铺语法 / Truchet | 少量几何组合成有秩序的复杂印花 | 采用，用在蓝色印花带与小材质样本 |
| 坐标扭曲 / 多尺度场 | 图案、纸纹和格线共同弯曲 | 采用，背景与印花共用空间映射，而非跟鼠标摆一张图片 |
| 参数化轮廓 | 胶囊、花边、邮票缺口、花形 | 采用，真实生成可变 SVG 轮廓 |
| 隐式曲面 / Marching squares | 多块印墨连接、分离、改变边界 | 采用，局限在按钮底材与小印墨样本内 |
| 印刷网点 / 有序采样 | 明暗通过点径与密度表达 | 采用，形成纸张印刷感 |
| 几何约束 / 邻点耦合 | 触碰沿纸边传播，法向与切向分别响应 | 采用，继承保存版的单时钟与轮廓求解思路，重做外观与形变 |
| 纸角曲面 / 多层遮罩 | 翘角、层纸、随压力变化的阴影 | 采用少量，避免变成厚重 3D |
| 反应扩散 | 自发增长的细胞、珊瑚等纹样 | 调查后不采用；本版需要保持参考 01 的明确平铺秩序 |
| 流场粒子 / 拖尾 | 大量轨迹形成流动 | 不采用；此次以纸、线、印花自身的变化为主体 |
| 纯色光晕 / 虹彩叠层 | 大面积色彩变化 | 不作为主要方法，避免再次刺眼或偏离蓝白手帐 |

主要来源：[The Book of Shaders · Patterns](https://thebookofshaders.com/09/)、[fBM / Domain Warping](https://thebookofshaders.com/13/)、[Karl Sims · Reaction-Diffusion](https://www.karlsims.com/rd.html)、[Codrops · SVG filters](https://tympanus.net/codrops/2015/03/10/creative-gooey-effects/)、[Red Blob Games · Noise](https://www.redblobgames.com/articles/noise/introduction.html)。这些资料支持方法选择；本版形状、配色、图案与运行代码自行实现，不引入外部运行库或素材。

## 固定实施计划

1. **风格与构图**：重新做当前静态入口，以 01 的蓝白手帐语言展示按钮、面板与基础小元素。控制背景和纸白的亮度，文字与细边清楚。
2. **生成式视觉**：实现规则印花、坐标扭曲背景、参数裁边、隐式印墨、网点与纸角；在空闲、掠过、按压时都有可实际观察的几何或材质变化。保存版只借鉴架构，不照搬其动效组合。
3. **交互与所有权**：所有动画由一个页面时钟管理；模块不自建计时器；保留暂停、减少动态、隐藏、退出清理。基础控件只展示本地视觉状态，不接业务。
4. **验证**：实际桌面/手机截图、轮廓及图案运动、按压/键盘/局部状态、暂停/恢复/减少动态、隐藏/退出、无业务请求及快照摘要检查。适当检查几何有界与绘制工作量，不以粒子数或测试数证明视觉达标。
5. **收口**：对照此计划、当前实现、差异和真实证据进行 Plan vs Actual；报告偏移与尚未验证项。

范围仅 `apps/web/public/design-lab/20261101/` 及忽略的本地测试证据。保护正式前端与其他已有修改；不提交、推送或部署。
