# 第三套 · 一致的材质系统

## 实施前依据

用户要求：“这套归档，现在做第三套，纸面板、纸按钮、纸背景，是可以的（不一定纸，但是要相互配合）”。这允许一套统一的纸感材质，继承此前纯 UI、清爽可爱、明显程序化、无角色主体、不做功能流程的要求；不再把“不要直接手帐”解释成禁止纸质材质。扭曲仍不采用。

## 计划

1. **先归档第二套**：将当前微蓝运行入口及四个资源独立复制到 `saved/02-soft-forms-20261101/`，记录摘要。后续不再修改它，也不修改第一套保存版。
2. **第三套独立风格**：以雾蓝棉纸与压印为统一材质，背景、面板、按钮、小元素共同使用纤维、细颗粒、吸墨、切边厚度和柔软阴影；保留可读性、少量灰紫点缀与圆润比例。不使用装订、书签、手帐构图或角色。
3. **强程序化视觉**：生成多尺度纸纤维和细粒高度场；由局部光照计算凸印/凹印与纤维明暗；参数化裁边与层纸厚度；生成对称压纹和网点；背景、面板、按钮共享光源及纹理语言。互动改变照明、压印/材质显影和压下深度，保持主体轮廓稳定，不用液态/坐标扭曲。
4. **样本与边界**：只做按钮、小按钮、面板、背景、标签、页签、开关、输入和加载装饰；本地视觉状态，无业务请求。动画保持单一时钟、暂停/减少动态/隐藏/退出管理；不用外部素材或依赖。
5. **实际验证与收口**：桌面和手机运行截图；材料与光照实际变化、轮廓稳定、按压/键盘/本地控件、暂停/减少动态、生命周期、失败回退、窄屏、两个归档摘要和独立入口。核对 Plan vs Actual，保留事实与未完成项，不以测试数宣称审美达标。

修改限独立静态样本与忽略的本地证据，不改正式产品源码、提交、推送或部署。当前 Vite 服务复用。第三套入口会单独提供，并把当前根入口指向第三套；已发给用户的第二套入口保留。

## 颜色补充

用户补充“不一定蓝色风，也可以红色风”。本套选择暖红方向：奶油棉纸底、莓红重点按钮、灰粉压纹。背景、面板、按钮统一调整到暖色材料，不保留原计划的蓝色默认值；材质和纯 UI 范围不变。

## 看过第三套初版后的修正

用户要求“颜色要更红为主一些，要更纸，同时更科技感一些”。提高红色纸面的面积与朱红印刷色的分量，纸张纤维从初版偏粗颗粒改成较细的方向性纹理。科技语言采用精密定位线、印刷网格、参数化几何线路、微孔与套色定位；仍为纯视觉元素，不增加功能或业务数据。保持浅暖底、稳定轮廓，避免金属/玻璃材料和扭曲。

## 最新配色合同（覆盖上一段红色面积要求）

用户看过后要求：“不对，回退，红为点缀，白为主”；并补充“红要比较纯的红”。最终使用白色纸面为大面积主体，红色集中于主按钮与少量标记，色相为清晰正红，去掉莓红、灰粉与大面积红纸。保留上一修正中“更纸、更科技”的材质和精密细节要求，不把配色回退误当成撤销材质工作。

## 最新材质合同（覆盖线路方案）

用户要求“纸的感觉要很强很强，真的纸，科技感不要通过这种线条表达出来”。撤销装饰电路、定位线、刻度、网格与环形科技饰边。最终以真实纤维、微毛边、厚纸截面、漫反射与压印为核心；技术语言改为纸上细小颜料单元的有序显影（电子纸式离散印点），以及材质自身的实时光照和压痕变化。无发光玻璃、液态扭曲或功能流程。原线路方案保留为过程记录，不通过换名继续加载。

## 最后材质与保留元素

用户要求保留面板印点星形，“整体要白一些，不要绵纸”，并再次确认“白为主题，红为点缀，纸的特征很明显”。最终选择更亮的细白纸：中性纸白、细密纹理、清楚裁边、薄纸截面与压印，撤销棉绒毛边和奶黄棉纸色。保留原来的五角印点形状和显影逻辑。`03-cotton` 仅为此前已提供的预览路径，保留地址连续性；可见标题与文案均已改为白纸。

## 面板与绘画的进一步修正

用户指出按钮内部也不要填红，并要求认真考虑美感、纸感、不一定规则的面板，以及面板响应应与纸/绘画有关。最终将主按钮也改为白纸，红只留图标和极少的小标记；面板采用有差异的裁纸/撕边几何，按压投影与表面压痕共享纸张材质。增加受限的干笔/石墨痕迹反馈，掠过和轻压在纸内短暂留下细笔迹，背景同样响应，随后淡去。这是纯 UI 触感，不提供绘画工具、文档、保存或业务功能。轮廓不做动态扭曲，印点星保留。此前单纯整齐圆角框加纹理的表达不再作为最终构图目标。

## 壁纸显色与小容器（最新授权）

用户提出寻找大肥鱼 / DS 娘壁纸作为背景，鼠标经过之处暂时涂色，要求不规则、有画笔感，并指出小容器追光不合适。允许本套在背景使用角色壁纸，覆盖原计划的“无角色 / 不用外部素材”，但不新增角色主体区或真实功能。采用 AATINF 社区素材 C77《成熟·办公桌场景壁纸》，下载原图并记录出处，不把第三方素材称为原创。

实施：缓存浅灰画稿与原色层；由方向、速度、种子与毛刷分束生成破边、断续显色蒙版，停留约 3–4 秒后渐隐，最长约 6 秒，有限笔触池。背景显色服从已有页面时钟，暂停/减少动态时冻结年龄，输入仍可按事件更新；图像加载回调先检查 Owner 存活，退出释放图像与离屏缓冲。小容器改固定柔光、纸边厚度、按压阴影与干笔吸墨，撤销指针追光及移动高光。白纸按钮、正红细节、不规则纸面板、印点星和纯 UI 范围继续保留。

材质调查参考：[Hahnemühle 画纸表面说明](https://blog.hahnemuehle.com/en/watercolour-paper-guide-which-paper-is-right-for-you/)、[Winsor & Newton 画纸选择](https://eu.winsornewton.com/blogs/guides/best-paper-for-watercolour)。采用平滑细纸与清楚笔触的设计取向；显色/淡出是 UI 的艺术化反馈，不宣称物理水彩模拟。

## 元素与背景的完成度平衡

用户反馈：“按钮、容器以及其他完全没这个背景惊艳”。继续打磨元素自身，而非只交付壁纸。加强可见的薄纸分层、截面短纤维、纸上描边的动态生长与局部干笔拓印；小容器光源保持固定。按钮维持白纸和压印字，正红仅作小笔触，轮廓不扭曲，不加功能流程。对比桌面静态与真实悬停/按压截图，验证像素反馈而非只确认事件触发。

材质照明固定后，活动入口缓存静止纸面；只为接触、压印、尺寸或后端变化更新表面材质。背景的纸纹也固定，背景动态由原色笔触承担，取消原先意义较弱的环境追光。这是根据当前绘画语言和实际渲染开销做的调整。笔触年龄使用同一帧时钟的真实可见时间，隐藏/暂停时冻结，不因计算变慢而把几秒钟拖成长时间。

## 圆笔、精简按钮与彩色点击（最新修正）

用户要求笔改圆形；页签选中态更明确；按钮只保留纸白按钮及“小按钮 / 迷你”，去掉其他不规则按钮；开关更丰富；按钮点击有“一下丰富多彩”的反馈。背景采用带细纸纹缺口的圆头笔，替代扁平分束刷。按钮统一为规则白纸矩形和三个尺寸；选中页签以更深正红文字、白纸层和红色短笔画明确区分。开关补纸片滑动、印记显隐和压印层次。点击时短暂展开多色颜料印点与小星花，再回到白纸；默认色调仍白为主、红点缀，彩色仅作本次用户明确要求的瞬态反馈。统一由原时钟管理，暂停/减少动态时给静态彩印，恢复后继续消退。保持纯 UI，不接业务动作。

## 笔刷与点击的最新收敛

用户指出圆笔过硬、消失应按时间而不是长度、外撒的彩色点击反馈太土；随后明确“用一开始的画笔，只是改成圆形”。保留最初分束笔纹、干笔留白与原色显影的取向，只改变笔头为圆形，不采用大范围柔焦笔。原先 156 段队列会在密集输入时提前删除年轻笔迹，改成 150ms 时间层与稀疏栅格块，同一时段输入合并，不按输入数量淘汰；停留 2.6 秒，再用 3 秒淡出。暂停与隐藏继续冻结本套的视觉时间。

点击反馈撤销外撒颗粒、星花和全屏覆盖层，改为按钮轮廓内、文字下面的三色纸面染印。用户确认“现在按钮效果非常好”，并要求页签、开关、标签、进度条拖动也采用这一感觉。延伸相同的局部纸面染印：页签染色随选中纸片移动；开关/复选框和标签在自身纸面内显色；进度条拖动时给已填充轨道染色，松开后淡回正红，滑块仍为白纸。标签使用原生按钮以支持同样的键盘反馈，仍然只改变本地样本外观。新增表现共用原时钟与颜色绘制器，不加业务行为。
