# 01 · 清爽、柔软的基础 UI 样本

入口：<http://127.0.0.1:5173/design-lab/20261101/index.html?rev=materials-r5-fresh>。

只展示按钮、小按钮、背景、面板、页签、开关、标签、输入框与加载动感，用这些元素判断整套界面的感觉。只保留 01；无角色主体、业务面板、流程或命令演示。

## 当前视觉

奶白、晴蓝、少量薄荷与粉色点缀。文字与轮廓保留足够分量；移除之前偏硬的压边、密集纹线、灰蓝金属感和强反光。悬停让边缘柔软地鼓起，按压产生局部凹陷，松开后回弹；不抬起整块卡片。

## 程序生成的部分

- `materials.js` 为 42 个表面独立采样闭合轮廓，使用相邻点耦合弹簧生成实际 SVG 路径。按钮文字有独立的轻微阻尼跟随，布局位置稳定。
- 面板、按钮、标签与小元素共用材质规则；光源位置实时改变。细粒来自代码生成的 SVG 图案，未加载位图材质或插画。
- `ui-field.js` 计算二维波场，以 WebGL2 绘制曲面法线和连续光纹。指针和按压只扰动视觉表面；无业务含义或功能依赖。WebGL2 不可用或着色器失败时使用 Canvas 2D 回退。
- 页签滑动与开关拉伸只展示控件自身的视觉状态。输入框只保留本地文本；没有保存、请求或后续行为。

`index.html` 只加载 `materials.css` 和 `materials.js`；后者只导入 `ui-field.js`。旧 `lab`、`console`、`kawaii` 文件和先前角色素材保留为过程记录，当前入口不加载它们。

单个帧时钟拥有几何、光照、弹簧与波场。手动暂停和系统减少动态停止持续运动，直接操作仍有效。页面隐藏取消帧；退出先失效，再解绑监听、断开观察器并释放 GPU 资源。

## 实际验证

当前代码通过 Playwright Chromium 的 34 项检查，实际覆盖：轮廓悬停、按压与回弹、小按钮独立几何、键盘按压、页签连续移动、开关拉伸、局部输入、背景帧变化、暂停/恢复、减少动态、320/390/768/1024/1440/1920 宽度、退出后无帧与迟到 DOM 写入、重复退出、WebGL2 缺失和着色器失败回退。浏览器异常及业务 API 请求均为 0。

已查看桌面、手机和波纹状态截图。证据在忽略目录 `test-results/design-lab-r5/`，检查脚本为 `verify.mjs`，结果为 `verification.json`。暂停截图对程序表面、CSS 动画和背景做逐像素比较；仅遮罩原生输入文字区，原因是 Chromium 对其字边重复截图出现过 1–3 级 RGB 抖动；输入框的程序边界仍参与比较，帧停止检查不使用遮罩。

模块语法检查通过。未执行生产构建、后端回归或专门的浏览器历史缓存恢复验证；本轮只改独立静态样本。正式 `apps/web/src/style.css` SHA-256 保持 `5427198548A0B098FBCB7CDE6079562A300D9ADE20B4C519B91248DDBFCA7680`。

## Plan vs Actual

完整过程依据保留在 `REFINEMENT-R2.md`，本轮以用户最终的“纯 UI 程序化”和“清爽可爱”修正为准。

| 要求 | 实现与处置 |
| --- | --- |
| 只以 01 为基础 | 只有一套基础样本；02/03 不再扩展 |
| 按钮、背景、面板、小元素定调 | 当前入口只陈列这些基础 UI |
| 激进的是 UI 程序化，与功能无关 | 实际轮廓、弹簧、光源和波场由代码生成；R4 的路由、逐步执行、轨迹、命令等是错误偏移，已从活动入口移除 |
| 清爽可爱，不要角色主体 | 明亮白蓝、圆润形变、柔和层次与少量彩色点缀；无角色图片 |
| 太轻、看不清 | 加深文字与主按钮、增大常用字阶，边界与面板底色拉开差异 |
| 后续指出交互质感偏离可爱清新 | 收掉硬压边、密纹与灰蓝反光，保留可读性；几何响应改为柔软鼓起和局部凹陷 |
| 独立、安全、可预览 | 无生产接口和业务文件改动；实际检查覆盖当前 UI 与动画边界 |

测试只能证明实现行为，视觉方向仍由用户判断。本轮没有把此前功能扩展继续解释为符合要求。
