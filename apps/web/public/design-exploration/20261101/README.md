# FishBot：三种新的日常

2026-11-01，依据最新 Pi 对话制作的独立交互预览。

## 打开

Windows 项目根目录运行现有 `npm run web`，打开：

- A 潮汐工作室：http://127.0.0.1:5173/design-exploration/20261101/index.html#tidal/robots
- B 鱼信事务所：http://127.0.0.1:5173/design-exploration/20261101/index.html#paper/robots
- C 深蓝指挥舱：http://127.0.0.1:5173/design-exploration/20261101/index.html#midnight/robots

必须使用 `index.html` 路径；Vite 对目录地址可能返回正式应用的 SPA 入口。

顶部切换版本；工作区导航切换机器人、能力与表达、资源与运行三个页面。

## 设计依据

Pi 最新对话 `2feaac4c-0931-4b3c-abb5-cb363324826c` 的用户要求：高级、可爱、精致，有明确交互；机器人卡片要与整体协调，减少过强的光效、抬起和左侧色条；制作多个更成熟的版本。

原演示混合加载多个样式文件，正式入口又使用另一份样式，导致讨论的效果与实际页面不一致。本预览使用自己的 HTML、单一 CSS 入口与脚本，通过明确的主题选择器组织三个方向。

| 版本 | 视觉与布局 | 侧重点 |
| --- | --- | --- |
| A 潮汐工作室 | 蓝白侧栏、连续机器人列表、轻量卡片、潮汐圆弧 | 日常操作清楚，接近成熟工作台 |
| B 鱼信事务所 | 暖纸横栏、编辑式字阶、机器人名片、今日鱼信 | 陪伴产品的辨识度与亲和力 |
| C 深蓝指挥舱 | 深蓝窄栏、合并数据带、安静的高对比信息分区 | 深色环境与资源监控 |

复用项目大肥鱼插画。动效仅包括短距离的入场、按钮与选项反馈；尊重系统减少动态设置，也可手动关闭。没有持续运行的粒子画布、外部字体或第三方统计。

## 交互范围

- 搜索与在线 / 离线筛选；机器人详情；离线恢复流程说明。
- 基础、表达、主动能力的分层；开关与示例参数编辑；主题切换保留当前页与页面内设置。
- 整机 / NapCat / 共享 AI 的独立示例曲线；高级指标说明。
- 键盘焦点、弹窗 Esc、搜索快捷键 `/` 与手机端布局。

所有账号、数字、趋势和动态都是示例，不代表生产实时状态。参数只在页面内存中保存；刷新恢复示例。创建、登录、保存等操作只展示本地反馈，不请求业务 API。

生产源码、现有前端样式及其他 AI 的前端修改分别保留；本目录不替换正式 React 页面。本轮管线修复已先提交推送 `3733c047c607c742151e396eded19c89539d8298`，这些后续设计预览留在 Windows 供审阅。
