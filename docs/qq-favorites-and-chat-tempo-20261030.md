# QQ 收藏接入与主要插件、聊天节奏核对

本轮授权：将机器人所登录QQ的收藏表情接入现有平台；追加只读检查高播放大肥鱼配置的节奏控制、主要插件覆盖情况。沿用 `qq-ai-saas`，修改前快照记录在 `test-results/qq-favorites/baseline.txt`，不改旧 Coopanion，不清除QQ会话。

## 参考项目实际上怎样控制节奏

以可访问的 [dafeiyu-config-pack](https://github.com/zexuanw958-svg/dafeiyu-config-pack) `8c01b0361b8a4baff5be3d2bc67ed55108953086` 的 `settings/pack.json` 为准，不把不同视频作者、MaiBot及全部大肥鱼混为一谈。

- GroupChatPlus开启群聊、关闭私聊接管。初始概率0.02、回复后概率0.8、持续120秒、群背景50条。
- 明确开启打字模拟：15字/秒、最大3秒。已下载插件 `utils/typing_simulator.py` 的 `calculate_delay` 按字数/速度，加±30%波动，限制0.5–3秒；短句与特殊格式走较短等待。`main.py` 在装饰阶段、实际投递前等待。它是发送前延迟，不是决定什么时候结束用户一轮输入。
- 配置包还开启2%错字模拟、25%戳一戳回应。我们的800ms连发合并/分条间隔不等于该打字模拟，不能称已经实现相同功能。
- 插件有注意力、回复密度和对话疲劳等可选机制；`_conf_schema.json` 和 `main.py` 的对话疲劳默认false，且配置包没有显式开启。不能说原视频版本默认使用了这些功能，也不能把它们列成我们已完成的能力。

## 主要插件实际覆盖

| 参考配置的主要插件 | 我们当前的实现 | 尚不等价的部分 |
| --- | --- | --- |
| GroupChatPlus | 受控实现插话、跟进、群上下文、沉默、连发合并和分条 | 按字数随机等待、错字模拟、戳一戳及完整注意力/密度控制未接入 |
| LivingMemory | AstrBot会话 + 每Bot/人物/会话隔离的持久事实、自述采集、纠正遗忘 | 未原样装插件，未完成其每10轮总结及向量召回 |
| Meme Manager | 真实图包、语境候选、35%自发配图、单张投递、独立启停；本轮增加QQ收藏 | 未原样装全插件，自动视觉审图/完整语义索引没有接入 |
| Proactive Chat | 受控实现主动联系、授权对象、安静时段、未回复抑制与额度 | 未原样装其全部功能 |
| Qzone | 未接入 | 不能发空间说说或浏览空间 |
| QQ Profile | 未接入 | 不能自动改签名、昵称或头像 |

语音/唱歌属于配置包另行选择、依赖额外服务的能力，当前也不能声称已经交付。我们的私聊仍偏收到消息就回应；有合并、分条和主动联系，不代表已经完成真人式的等待和收尾。

## 本轮收藏功能的边界与实现

- NapCat `fetch_custom_face_detail → MsgApi.fetchFavEmojiList → QQ原生服务`。实际接口在前一轮只读探测中返回200和3条请求样本，不代表账号仅有3条收藏。
- 同步只经受控本机OneBot端口，浏览器不能提交任意协议地址、URL或路径。原生在线身份、平台绑定QQ及提交前身份需要一致；异步同步期间切换账号或删除实例会使旧任务失效。
- 每Bot缓存独立，索引原子替换；原库保留到新库完成。不把收藏同步成QQ账号上的新增/删除操作。修改场景/启停只影响本平台。
- 最多同步200张，下载8MiB上限，经过一次性Pillow子进程验证/压缩，输出每图不超过1MiB、最多48帧、保留透明动画。不是每Bot新增常驻模型或服务。
- 说明优先采用QQ收藏的修改文字/描述/OCR；没有说明的先停用，页面可填写用途并启用。没有调用额外视觉模型，不冒充已理解图片。
- runtime只接受真实事件的 `self_id` 匹配收藏索引账号；不同Bot、不同QQ、普通图库不互用。明确要求“收藏表情”时只给收藏候选，而不是拿内置小黄脸冒充。
- 按用户后续要求，QQ收藏自动选用默认关闭；同步、预览和编辑保留。发送图片本身不要求描述，但语境选图需要说明/识图。本次实际7张由开发过程人工查看并补好场景，仍关闭总开关，不自动使用；不改变预设大肥鱼图包。
- 网页“聊天表情包”内新增独立收藏区，提供同步、进度、预览、场景编辑、总开关和单张开关。数据设置即时生效，不要求重启QQ或AI。

## Plan vs Actual 与验收

计划是同步→持久缓存→独立管理→真实SDK发送，保留动画及账号隔离；节奏任务是源码核对，不在收藏迭代里暗加新的聊天默认值。同步使用现有媒体文件存储方式，没有新增重复数据库状态或任意Python插件。

验收证据、实际同步数量与运行状态补充在本文件结尾。自动测试与真实QQ消息投递分开；未发送新真实消息时不宣称用户已收到收藏图。
