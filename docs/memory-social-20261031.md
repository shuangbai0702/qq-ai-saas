# 内存与社交功能实施依据

原始依据：2026-10-31 用户“FishBot 内存管理与机器人社交功能优化”整轮要求；本轮禁止 Git 操作。

| 要求 | 实现位置 / 验收 |
| --- | --- |
| NapCat/共享 AI 48MiB、独立16MiB、40秒PAGEOUT | 主机控制器；实机 memory.high/max、整机 RAM/Swap/zswap/PSI、真实 QQ 收发 |
| 实际 AI 活动及18秒宽限，不统一唤醒公共组件 | behavior/runtime_care 活动文件与控制器；非触发消息、长请求、任务结束及共享隔离测试 |
| 无效回收退避、连续回退冷却 | 控制器与独立 guard；针对性回归及主机采样 |
| 亲密度、情绪、记忆分离 | BehaviorStore + data_admin；真实事件、去重、频率限制、持久化、重置、租户/会话隔离 |
| 可信主人身份进入对话 | 协议 sender_id + 当前成员配置 -> 平台系统上下文；认主回复与伪造身份边界 |
| 远程语义召回 V1 取舍 | 现有远程 Embedding + SQLite 索引/检索/注入；真实服务能力和受控故障验证，不增加常驻模型 |
| 其他社交能力可靠性 | 现有普通记忆、人格、群触发、表情、图片、权限与隔离入口回归 |
| 部署/保护/同步 | 新备份与回退；仅控制器及必要 AI/Web 更新，不重启 Agent/NapCat/QQ；Windows/Linux 修改文件 SHA256 一致 |

## 实际实施

1. 主机控制器空闲阈值改为 NapCat/共享 AI 48MiB、独立 AI 16MiB；生产显式配置 18 秒宽限和 40 秒 PAGEOUT 最短间隔。API、Agent、PostgreSQL 原 128MiB 策略保留，未设置低 memory.max。
2. 非触发群消息不再写 AI 活动时间；活动只放宽其所属 AI，不统一唤醒 API、PostgreSQL 或其他 AI。真实推理、表情处理、表达学习和摘要任务均登记工作状态；长任务刷新活动，结束/取消释放状态，迟到任务不能唤醒已释放成员。
3. PAGEOUT 前要求进程空闲、无有效活动标记，校验 PID 创建时间和 cgroup 所有权。只有仍有至少 4MiB 驻留匿名页才尝试；一次实际驻留减少不足 1MiB 时按 80/160/320/600 秒退避，有效回收恢复 40 秒。每次最多一个 helper，超过时间或活动恢复即终止。
4. 独立 OOM/PSI Guard 保留；连续回退的恢复冷却从 30 秒逐次翻倍至最多 600 秒，状态落盘；持续稳定后重置。控制器退出自动放宽限制，不影响 QQ 登录状态。
5. 亲密度从“仅三个正面关键词改变”改为真实定向互动累计：普通交流间隔至少 300 秒，明确正负表达至少 60 秒，每人每会话每日最多变化 10 次，范围 -20～100。按真实消息 ID 去重，去重记录保留七天；群聊路过和内部定时事件不加分。情绪约五分钟恢复，普通流量不延长情绪期限。长期记忆关闭不再关闭关系/情绪。重置保留事实及防重放记录。
6. 主人身份由当前成员配置与协议 sender_id 比较，空主人配置不会认主；平台上下文明确要求人物称呼/态度区分主人和普通用户。记忆、昵称、聊天文字不能更改身份，工具权限仍独立校验。补充人物口吻要求；模型措辞仍非强确定性，不将其当成权限保证。
7. 远程语义索引、SQLite 持久化、逐步检索、注入、额度、故障回退和迟到删除围栏已有完整链路。当前生产远程服务模型列表未列出 Embedding 模型，所有现有机器人均关闭且未配置向量模型；本次不擅自选择付费模型或开启语义召回。界面标明实验功能、V1 默认关闭及远程服务前提。普通事实/关键词/摘要记忆继续使用，不增加常驻向量进程。

## Linux 实际结果

部署前现场观测（相邻时点，非受控 A/B）：整机 RAM 约 784.4MiB，Swap 568.0MiB，zswap 117.5MiB；NapCat PSS/USS 约 136.0/120.6MiB，共享 AI 约 37.0/36.0MiB。

剔除编译与隔离测试负载后，90 秒、10 次生产采样：

| 指标 | 中位数 | 范围 |
| --- | ---: | ---: |
| 整机实际 RAM | 727.2MiB | 716.1～769.6MiB |
| 可用 RAM | 1048.1MiB | 1005.7～1059.2MiB |
| Swap 逻辑页面 | 635.7MiB | 634.5～640.6MiB |
| zswap 实际物理池 | 128.1MiB | 127.2～129.4MiB |
| NapCat PSS / USS | 58.7 / 52.6MiB | PSS 54.3～129.4；USS 48.2～123.3MiB |
| 共享 AI PSS / USS | 13.9 / 13.2MiB | PSS 7.3～15.3；USS 6.6～14.7MiB |

这不是固定内存承诺，NapCat 有明显驻留反弹。48MiB 是软回收阈值，不等于 PSS/USS 硬上限；页面可重新换入，cgroup charge 与进程驻留也不是同一口径。zswap 已包含在整机实际 RAM 中，不另行累加。不能将 PSS、USS、Swap 相加。

该窗口新增 OOM 0、保护回退 0；PSI full 最后 avg10=0.01%、avg60=0.17%，没有持续高压换页。仍有换入/换出（1509/2385 页），不能声称完全不换页。构建/测试期间曾出现明显临时压力，已单列而未作为稳定占用结果。

实测 NapCat/共享 AI 的 memory.high 均为 50331648 字节。基础容器无新增低 memory.max；独立 AI 无在线实例，本轮仅保留16MiB配置与分类回归，未做独立账号实机负载测试。

## 功能与保护验收

- 主人真实 QQ 发来的两条私聊：2 个真实消息 ID、2 次 AI 请求、2 次成功回复、0 次失败；亲密度由 0 变为 1，情绪开心。频率限制阻止第二条短间隔消息再次加分；最终 AI 重载后，经现有运行时管理 API 读取，分数仍为 1。
- QQ 历史回查确认实际收到了称呼及认主回复。另用真实远程模型、隔离身份上下文验证主人与冒称主人者区别；隔离测试不写生产关系分数。
- 真实 QQ 文字/图片投递约 317/394ms，协议消息回查成功，在线状态正常。真实两条入站首段回复约 7 秒、4 秒；第二条模型调用为 2842ms。样本不足以证明统计意义上的额外 P95≤5秒，不能以这两条消息宣称已完成 P95 基准。
- Windows、Linux 均完成构建。Linux 主回归31项首次29项通过；修复测试夹具后，图片相关3项及内存1项复验通过，覆盖原两项失败。另有主机控制器10项、Guard6项通过。
- 覆盖普通事实记忆、摘要、人格上下文、情绪期限、群触发、不触发消息不写 AI 活动、实际请求占用/释放活动、共享成员/群/发送者隔离、亲密度持久化与重置、主人工具权限、表情收集/审核、图片/图库投递、配置迟到回写与 QQ 绑定竞态。外部真人群成员/图片入站未逐项实发；图片入站由真实 AstrBot SDK + 受控协议夹具验证。
- 用户、租户、成员关系、配置版本、模型密钥、QQ 绑定六张表与部署前 pg_dump 数据逐行一致。SQLite 使用 backup API 备份；保留 QQ 会话与身份目录。API、Agent、NapCat、PostgreSQL 基础 PID 未变，只因 Python 聊天实现更新单独重载共享 AI；Web 仅替换静态产物。
- 临时测试容器全部清理，仅原四个基础容器运行；真实运行资源为一个 NapCat、一个共享 AI。既有离线清退逻辑保持，本轮没有再次强制生产 QQ 离线。

## Plan vs Actual

内存策略、关系规则、可信身份注入、UI 说明、Linux 部署、数据保护和回归均已实施。未引入额外常驻服务或改变 PostgreSQL / API / Agent 架构，未执行 Git 操作。

合理偏移：没有开启尚无已验证服务/模型的语义召回；按用户 V1 退让条件保留关闭。生产亲密度不做破坏性重置，以隔离 SQLite/运行时管理用例验收重置；真实生产只验证自然增长与重载后保留。没有为了监控或 Web 重启任何协议/Agent。

Linux 验收环境先修正了工作目录写权限、编译器堆上限、测试目录及源码 PYTHONPATH。另发现两个旧测试不可靠：Linux 分支误将整个 ctypes 模块 mock 且只在 Windows 分支导入 call；表情用例在70%概率下断言必定发送。改为仅 mock 系统调用、跨平台导入 call、明确将测试夹具概率设为1；保留所有资源所有权、次数和隔离断言，未降低检查强度。

尚未收口的量化项：额外 P95 的统计基准、长期高负载下的稳定内存；不得据短窗口宣称完成这些长期指标。自动回退保护保持启用。

Linux 备份与原始验收证据：`/opt/fishbot-social-20261031`。保留 `backup/platform.sql`、各机器人 SQLite 一致性备份、旧主机控制器/Guard/应用文件和 `backup/web-dist.tar`。回退静态页面可直接恢复旧产物；主机策略回退恢复旧脚本并撤回本轮 `48m.conf` 后重启控制器/Guard；AI 代码回退需要同样的 AI 单独排空重载，不能顺带重启在线 NapCat。源文件摘要另存验收清单，不将含账号/密钥的原始证据提交仓库。
