- 附件身份/租户/Key 优先级保持；未替换既有安全机制，未迁移数据库或现有机器人。

- 内存历史使用容器整体用量与 API RSS/heap；不提供逐 bot RSS 相加的误导总数。额外采样有界，CPU、峰值内存与启动时间增量未实测，未运行压力试验。
