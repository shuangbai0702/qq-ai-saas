## 实现边界

- 外层决定目标和下一项任务，内层进行具体模型与工具执行。任务完成、受阻或预算退出后重新交还外层；不预先机械执行长串固定任务。
- 工作绑定 tenant、bot、epoch、generation、revision 与稳定 action ID。QQ离线不自动启动，模式切换撤销过期许可。
- 工具授权来自内层实际配置，外层只获得可用目录，不拥有第二套能力开关。B站当前为搜索与公开资料，不是完整视频运营能力。
- 正常用户消息优先；仅旁听、尚未执行的普通群事件不会伪装成新的执行反馈，避免持续废弃外层判断。
- 上下文复用已有摘要、近期未压缩消息和受控跨会话投影；执行经历提供已提交决策时间、任务及实际结果。各机器人分别隔离，不另建一套人物记忆。
- 外层群聊不再继承标准群参与间隔；白名单、安静时段、真实联系人和末端发送保护继续保留。
- 文本软换行修复与分条发送分开处理，保留自然段和1–4条输出自由；图片不重复发送，原生At身份及配置换代仍受校验。
- 结果不明不能盲目重发，模型叙述不能当作QQ或空间的成功回执。

## 已运行验证的类型

实施过程中运行过生命周期与隔离单测、原生SDK工具/媒体/分条回归、真实模型隔离调用及授权QQ实测。对应测试位于 `tests/autonomous-*.test.ts`、`tests/autonomous_pipeline_test.py`、`tests/native_internal_test.py`、`tests/reply_rhythm_test.py` 等。测试替身不等于真实模型，协议接收回执也不等于所有远端展示效果。

本次源码归档另外执行构建与针对性回归；最终结果以本次交付说明为准。历史运行记录只证明当时对应版本，不能冒充当前完整生产验收。

## 运维与回退

48MiB空闲memory.high、40秒PAGEOUT、Swap/zswap、Guard及离线清退策略保持独立。自主循环可单独切回被动模式，保留账号、Key、记忆和目标记录。Web/API发布不顺带重启QQ。

发生过测试临时数据库耗尽磁盘并影响服务的事件，不能隐去：测试夹具已加入其临时目录清理，后续生产测试必须先检查磁盘余量，禁止在小服务器盲跑完整集合。原始事故与恢复证据保留于私有运维记录。

源码同步不代表重新部署。恢复服务需使用已核对的产物和数据备份，数据库、Master Key、QQ身份/Session必须完整保留。
