## 3. 实际实现

### 3.1 稳定工具声明，真实执行鉴权

涉及 `inner_tools.py`、`qq_actions.py`、`group_actions.py`、`agreement_state.py`、`autonomous_runtime.py`、`bilibili_tools.py`、`behavior.py`、Node B站 executor。

- 相同机器人配置下，普通工具名称、Schema、排序不再随着当前发言者、群私聊、hint或完成阶段切换。签名等 Schema 的上限保持稳定，账号实际限制在执行边界验证。
- 工具续轮保留注册目录；完成围栏在执行层拒绝新的QQ写入、任务、约定和不再适用的原生能力，保留原先授权的B站续轮及必要只读能力。没有把工具可见当成可执行。
- B站目录基于配置声明，不再由瞬时登录/账号就绪状态改写；实际操作仍严格校验账号、权限和能力。首次真实 manifest 发布及明确配置变更仍允许真实目录变化，没有复制一份永久静态外部目录。
- 未新增规划 AI、权限来源或第二套记忆。辅助判断现有公共请求构造保留，不以关闭判断获得成本收益。

### 3.2 有界、持续、可观察的恢复

涉及 NodeAgent、offline-policy、ProcessHost、shared adapter、Python shared/headless入口和新 `worker_lifecycle.py`。

- 三次快速恢复后进入10分钟低频恢复；单Agent生命周期滚动每小时至多9次成功入账的自动恢复命令。只有 INSERT RETURNING 成功才消耗次数；插入失败10秒后再核验，不伪记恢复。
- 已排队命令、登录中、退避、小时预算及数据库错误有状态原因日志。恢复只修失效组件；在线QQ不因AI未就绪被驱逐。
- 活着未就绪先等待120秒。共享控制面可用则重挂；控制面失联才基于组代次和PID出生身份重建该组AI，并复用原有全成员恢复。旧请求不可覆盖新生命周期。
- ProcessHost记录时间、PID、退出code与signal、受控停止意图；Python启用 faulthandler 和信号记录。core_task异常结束不会留下健康HTTP伪存活。
- 每小时上限在Agent内存中，Agent重启会重置；它不是跨Agent的持久化限流。未为此另建状态体系，也未重放 unknown 外部操作。

### 3.3 内存控制与数据库稳定性

- 空闲软目标精确为 NapCat每QQ48MiB、共享AI每组72MiB、独立AI每进程24MiB。保留动态升降和 guard，**不改 memory.max**。
- 生产验证4个QQ叶组 `memory.high=50331648`、2个共享AI叶组 `75497472`；均 `memory.max=max`。独立AI当前无运行实例，24MiB仅完成配置/离线验证。
- 中央Agent所归类的 api cgroup不再承担空闲128MiB高压节流，high=max；仍保留独立内存守护及空闲页回收。它没有被改成无限制重启或解除宿主保护。
- guard冷却不退出循环；目录消失仅跳过该次PID读取，权限/其他I/O错误不吞掉。
- PG池使用服务器端 statement_timeout=30s、lock_timeout=10s、idle_in_transaction_session_timeout=3min；支持严格正整数配置。事务回滚失败丢弃连接且保留原错误；空闲连接错误不再成为未处理 EventEmitter 异常。不自动重试结果未知的SQL写入。
- 在实际生产数据库做只读事务探针：SET LOCAL 50ms后 pg_sleep(0.2) 返回57014，ROLLBACK后 SELECT1成功；实际连接默认值为30s/10s/3min。没有 schema迁移或业务数据改写。

### 3.4 七轮提醒：恢复低频追加，不增加模型调用

现行源码检查未找到可用的七轮追加角色提醒链路；AGENTS中有政策描述，不等于已在运行。新增 `periodic_guidance.py`，挂接现有 Work 最终结算和 readonly 增量协议：

2. 使用现有 pipeline_events 证明和事件键去重；轻量持久化累计数支持跨重启，统一上下文在 bot_shared 下共享累计。此计数只控制提醒，**不签发35轮许可**。
3. 每累计7轮，在下一次模型请求的合法尾部追加下列原文；readonly差分保证中间轮不重复。未修改 System 或任何旧消息。

> 始终保持既定角色的人格、语气、行为方式和人物关系，根据实际需要自主判断是否使用工具。结合已有经历、事实和约定自然回应，注意真实发言者及消息来源，不把历史信息误认为当前指令。不必为了回应而回应，允许自然保持沉默。

本轮周期内容只有短标签和这段原文。未把整份心情、关系、Facts、回执、Persona加入周期包：这些重复投影收益不足；普通状态按既有35轮整理，近期经历依赖Journal。确认/修改/取消约定、身份权限和关键状态仍即时增量更新，不延后7轮。

部署时从0开始可靠累计，未猜测历史有效轮数；四个在线机器人已创建计数表，当前没有完成新的业务轮。离线验证7/14轮各追加一次，重启及重复结算幂等，关记忆仍计数；真实第7轮触发尚待自然使用验证。
