# QQ账号绑定固定规则实施记录

依据：用户要求“那就不允许切，只能删机器人”。本轮仅固定机器人与已成功登录QQ的绑定关系，不迁移、不删除既有记忆，也不主动删除任何机器人。

## 实现

- 首次成功绑定前，连接页仍可填写或纠正预填QQ；首次绑定后只允许原QQ恢复会话、重新登录。页面显示固定绑定及删除重建说明。
- QQ账号修改API不允许修改或清空已有绑定；普通配置保存也不能修改账号字段，避免绕过专用入口。
- Agent上下文优先读取已有可信QQ绑定，即使最初预填留空也不能用另一QQ替换。
- 登录成功提交、运行恢复重绑均在原机器人行锁内重新读取绑定及预填限制，拒绝不匹配身份；保留原有generation、取消、身份冲突及协议停止保护。
- 删除原机器人后新建产生新的bot ID及存储目录，原记忆不会自动附到新机器人。不增加第二套记忆或账号权限系统，不自动删除或换号。

## 验证

Windows账号、登录生命周期及新用户登录共5项回归通过；覆盖普通配置绕过、绑定后换号、空预填保护、错误扫码、删除重建、多租户拒绝、迟到身份探测及登录等待中的绑定竞态。浏览器验收通过首次预填、绑定后无编辑框、桌面/手机布局、后端拒绝换号及删除流程。生产构建和TypeScript检查通过。

Linux真实编译产物隔离API/Agent测试与线上发布结果待下文实测补充；未使用生产QQ做错误扫码实验。
