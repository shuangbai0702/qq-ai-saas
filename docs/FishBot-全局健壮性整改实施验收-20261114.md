## 基础能力收敛

- `context_protocol.scoped_event/scoped_event_hash` 统一事件身份的原字节格式；shared 保留原串、semantic 保留 SHA，两者用途不混同。Unicode/数字/转义字节等价验证通过。
- `credential_redaction` 收敛记忆、压缩、连续性、捕获的凭据语法，保留 8/12 阈值和 Bearer 差别；autonomy 的无词边界拒绝语义未强行统一。公开护栏匹配真实运行凭据，不按 sk-/Bearer 关键词封禁。
- `fs-atomic` 统一收藏索引、收藏同步、图库元数据、图包设置与心跳 rename 的 Windows 短暂占用重试；保留原心跳单 Owner、单写队列及进程身份。
- `bridge_http` 收敛原 Goal、周期模型预算、外部副作用预算的认证 POST；权限/CAS/租约/错误解释仍由调用方与原权威后端负责。execution_memory 的分块和 1.2 秒合同未改。
- 未为统一而统一 Journal 容错读取、不同业务日预算、权限事务、single-flight：报告只是候选提取建议，当前职责、失败语义不同，没有新增第二套基础框架或账本。

## Plan vs Actual 与发布状态

原计划的安全边界保持：主 Journal、B 增量、35 轮许可、Goal/Action/ToolEffects 账本没有新 Owner；旧消息和 System 不重写，重生成只追加校正反馈。报告中的旧华为云操作按用户要求排除。

合理偏移：拒绝自动清墓碑、未知任务/旧目录、历史 issue；以保留证据及可见 degraded 替代危险自动修复。未接入未经授权的外部通知服务；通过原 health 与日志消费异常。抽象候选按实际语义选择实施，未进行全仓机械重构。

本文件首次提交时：代码/隔离增量验证完成，干净构建、生产备份和部署验收待执行。不得把本地测试写成生产修复生效。最终生产版本、SHA、回退证据和健康结果将在验收后追加。

剩余边界：开放的恢复债务需要按证据处理；新登录账号上游凭据曾返回 401，不能借用其他账号凭据；未知 Scope 的 overflow 不能安全自动复位。护栏识别已知结构化协议和真实凭据，不宣称能识别所有自然语言泄密；明确引用/技术代码块允许的边界仍需后续真实流量观察。
