# 连续群聊接话增强（2026-11-01）

目标：增强机器人已经参与对话后的持续接话，避免关键词和随机筛选打断自然交流。

实现：按每个机器人、群、实际被回复的发送者记录对话关系；当前双方请求与回复共同构成话题。在已有接话窗口内，同一聊天者继续说话不经过关键词门槛，非零接话概率提升为确定进入回复处理。保留显式关闭、群白名单及发送代次保护。连续聊天按对话回应处理，不受主动插话的安静时段、疲劳与小时配额拦截；这些保护继续约束主动插话。其他成员仍可通过话题相关性进入对话，不新增模型分类请求。

Plan vs Actual：最初考虑短句及指代词识别；依据用户要求取消这些额外门槛，改用实际对话关系。另修正连续回应被误计入主动插话的问题；未修改任何疲劳/配额配置值。没有修改前端、配置版本、协议进程或内存策略。

验证：Windows 最终状态与群聊回归2项通过；Linux隔离环境相关测试7项通过，包括无共同关键词的连续追问、其他成员无关消息、疲劳和小时配额、配置应用不重置配额。Linux部署后4个QQ在线、AI就绪；Agent与4个协议进程PID和创建时间保持不变。共享AI等待空闲后重新加载。未取得部署后的真实QQ连续接话回执，回归测试使用Mock协议，不冒充真实收发验收。
