# FishBot 增量上下文上线与真实私聊验收

日期：2026-11-06（Asia/Shanghai）。本轮不执行 Git 写操作，不部署前端，不使用其他用户的 Key 做额外请求。

## 当前实现

采用用户最后确认的“新增或变化只追加一次，旧短尾巴可以保留”方案。不是最初“只保留最新快照＋显式断点”的方案；当前中转对所测试的断点字段返回 400，未发送不支持的字段。

- `adapters/astrbot/decision_context.py`：同一机器人的相同核心便签仅提供一份；明确归属的资料转换为完整、带来源的不可变记录；当前选用材料、目标及联系人等用顺序变化表示。未知字段保守保留，当前输入可无损还原。
- `adapters/astrbot/decision_history.py`：外层 orientation/planning 分别追加消息块及真实模型 JSON 回答；不合并旧块、不伪造确认、不新建持久记忆。只有新资料和实际变化进入新增块。
- `adapters/astrbot/autonomous_runtime.py`：公共决策入口接线；能力候选留在实时变化中，身份、工具授权和末端权限不变。真实数据库摘要版本变化、遗忘、配置代次、取消、异常等使传输历史退休；话题检索选择变化本身不误清空历史。
- 运行值使用一次布局和后续稀疏更新；旧值保留历史含义，最新值才是当前状态。最多 30 个决策轮，160,000 历史字符、32,000 新增历史字符、30 分钟空闲边界，可能提前重建。不会为了缓存延迟摘要或遗忘。
- 本轮不是所有入口的缓存重写：前台与内层已有布局保持；本次新增主要作用于外层。能力、权限变化造成的必要重建仍然保留。
