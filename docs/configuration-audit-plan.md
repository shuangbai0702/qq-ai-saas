# 配置合理性与使用体验复核

依据：用户要求检查每个配置的合理性、易用性及是否生效，发现问题直接优化；不做内存实测。沿用既有平台和能力管理，不扩展为新插件开发。

范围：人格/模型、触发/节奏、记忆/表达、图库、主动联系、数据操作、保存与生效状态。

1. 修复主动概率被轮询放大、随机插话先扣额度再被冷却阻止；验证边界和持久化。
2. 拆开分句、跟进、消息合并和发送间隔，不用单开关隐式重置参数；保留旧配置值。
3. 明确总开关/记忆依赖、未保存与未生效、零额度/安静时段/无授权目标等阻塞原因。
4. 清空学习后允许从新消息重新学习，继续阻止在途旧批次写回；人物筛选必须真正筛选人物状态。
5. 改进初次读取失败、编辑体验和输入说明；保存后不得因后台刷新时序误报版本冲突。
6. 用 Python/接口/原生运行测试和真实隔离浏览器验证，构建后更新当前本地服务；不修改真实账号配置、Key或登录文件，不发真实QQ测试消息。

最终以实际日志做 Plan vs Actual。没有承诺完整自动收图或个人风格训练；不把这些未接入能力显示为已生效。
