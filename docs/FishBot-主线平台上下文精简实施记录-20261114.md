## 实测数据（真实上下文编辑副本）

原 420 条主 Journal 只读提取到本地私有目录；生产原文不入 Git。媒体不参与下表比例。真实 M414 服务消息由 44,938 字符变为 514；其中 currentGoals 由 39,923 变为 12 字符（该时刻当前 Goal 为空），不再附带 164 条旧责任。**这是同一历史样本按未来规则重建的对照，不是删掉生产旧消息。**

|样本|前/后字符|前/后代理 Token（cl100k_base）|接口报告的前/后 input Token|
|---|---:|---:|---:|
|主人私聊|64,049 / 57,277|32,413 / 29,382|26,863 / 24,268|
|自主服务|103,829 / 57,142|59,257 / 29,191|48,606 / 24,073|
|普通群成员|58,760 / 58,270|30,131 / 29,739|24,928 / 24,656|

通过用户授权兼容接口先发现模型，再使用返回的 `gpt-6-luna` 做 3 组、6 次有界流式调用，另做 1 次群聊身份针对性检查。最初 `deepseek-v4.1-flash` 的真实大样本请求返回 HTTP 400，未计作通过；小请求可响应，未证实 400 具体原因。没有向真实 QQ/B站发送测试消息。

三组前后均正确区分主人/非主人/自主服务，未把服务触发当新授权，未把草稿当发送回执，也未把没有图像模型的失败视频分析说成成功。真实样本中当前 Goal 均为空，**不据此宣称非空 Goal 真实模型验证通过**；非空 Goal 的 revision、原约束和进度有确定性测试。

群聊样本存在两侧共有的事实理解偏差：虽 `directed_to_bot=true`，模型都把 @ 机器人解释成 @ 其他成员。补充 self_id 后的单次检查仍有同类错误，不能宣称该项已修复。因此保留原参与提示与后端准入；精简不依赖该判断成功，也不取消工具/发送权限检查。不扩大付费调用来追求措辞一致。

可报告缓存字段的后侧请求均为 cached_tokens=2,176；部分前侧响应未报告缓存。未报告不等于零，不能推导生产缓存改善比例。没有获得接口单价或优化后生产实际账单，不能承诺货币收益。老 35 轮内的已提交大消息仍按原样进入请求，主要收益随未来必要追加和合法退休逐步产生。

## 验证范围与 Plan vs Actual

复用原架构、预算、工具副作用幂等和未改变业务路径的既有证据，不重跑完整矩阵。实际运行：CurrentGoals 7 项、GoalDelta 5 项、BriefExperience 8 项；真实 SDK 单一综合用例（首次、重启、工具续接、候选提交故障）在相邻代码变化后按影响补测；35 轮真实语义退休用例 1 项；时钟/来源传输 ViewAnchors 3 项及最终时钟改动补测 1 项；Goal 上限数据库边界测试 1 项。测试中故障注入的 stage rollback 异常是预期路径，不是生产错误。新增上限测试最初误用方法名导致失败，改用真实 acceptHandoff 入口后通过，未削弱断言。

本批尚未完全覆盖的任务：Action/ToolEffects 仍承担恢复及未知副作用保护，未删表；真实在途 Action 的自动信息、旧基础区中的 execution_experience、tool_context 目录、social 候选、recent_burst、dialogue.deliveries 仍有保留项。不能把整个 30.5 万字符都视为可删，也未宣布主线执行材料已经全部退休。Scope 切换导致仍在途资料重新选入的剩余路径须继续收敛，不能用新 Scope 版本池解决。

当前来源/时间/约束的必要数据及发送回执保留；稳定 policy 全文只在其真实值变化时由既有 Journal 比较决定是否追加，本批仅删除已由当前事件身份表达的场景说明，未实施规则字典，也未把每七轮提醒变成其他周期。
