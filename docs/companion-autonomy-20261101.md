# 持续社交与自主群联系实施（2026-11-01）

## 原始要求与实施计划

用户要求实现并默认启用自主选择群成员与时机、参考大肥鱼的注意力/情绪/语义召回、持久偏好及长期动机；直接部署验收，Git 等待明确指令，不提交或推送。

1. 扩展每机器人 SQLite，兴趣与用户事实分开；偏好有表达/人格来源，共同话题只累计热度。保留会话隔离、容量及衰减。
2. 已有主动调度器增加候选群与成员选择；只用见过且曾直接互动的成员，发送前协议核对在群身份；拒绝、告别、未回应、安静时段、白名单、每日及每小时额度继续有效。
3. 注意力允许人格兴趣与自然短接话，相关兴趣热度提高既有随机进入概率（不超过20%）；直接@不受自动接话限制。
4. 持久单主情绪状态及连续心境；指向证据、否定与引用排除、道歉清零、中性交互释放、TTL。
5. 默认语义召回；无 Embedding 配置时用同一远程模型限时重排事实/摘要，预算、错误冷却及删除/配置代次围栏；配置向量模型时保留原检索后端。
6. 前端说明与开关默认值；已有机器人追加配置修订，旧版本与数据保留；Linux 隔离测试、构建、空闲AI更新和API独立更新，协议/Agent保持运行。

线上模型列表未提供Embedding模型，现有4个运行机器人均没有配置Embedding模型名。故默认自动选择远程聊天模型语义重排，单次2.5秒超时，共用每日向量/语义预算；失败冷却15分钟。不能将回退关键词称为成功的语义命中。
