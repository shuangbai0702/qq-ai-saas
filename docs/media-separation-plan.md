# 表情与图库分离实施依据

用户要求区分QQ内置表情、从QQ聊天自动收集的表情包和普通图库，并优化现有产品。

1. 保留现有手动反应图和客户配置，独立展示QQ内置表情开关；普通图库使用独立API、目录、候选标记和默认关闭的发送配置。
2. 增加按授权群收集聊天表情包：默认关闭，只收协议标记的表情图片；限下载大小/像素/并发/每日次数/候选数量，只进入待审核。人工补充使用场景后才成为原群回复候选。首版不自动视觉识别，不读取手机收藏，不把普通图片全部当作表情。
3. 实际收图在消息触发判断之前，不要求每张表情都@机器人；禁止收自己的输出，配置替换/停止/删除后不允许旧任务写回。
4. 待审核、批准、丢弃、移除、预览通过现有运行Owner管理路径鉴权；跨Bot/跨群隔离，普通图库不进入表情候选。GIF等仅保留受限首帧PNG并在页面说明。
5. 增加下载失败/限额/迟到/隔离、真实SDK事件、API权限、审核和网页操作回归。执行构建与生产检查，备份后更新现有8787；不做内存测试，不修改真实QQ登录文件，不发未授权消息。

最终按实际结果做Plan vs Actual；自动识图、读取QQ收藏及完整动图支持不在本轮承诺范围。
