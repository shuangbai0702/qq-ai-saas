## 实际实现

- 一次完整批次请求提供全部文字、来源关系、图片、真实工具状态及已有记忆；保留35个合法完整业务轮与管理员明确例外，无600条机械截断、无额外摘要层或压缩调用。
- 模型做有损语义选择。保存摘要、现有各类记忆后，整批许可替代逐事件Coverage/逐图批准；Journal成功替换后清理热材料、来源列表、引用副本、归档及可证明属于本批的原图。新批次引用保护和失败重试不变。
- 去除摘要输出和已选记忆产物的静默截断；真实容量不足明确失败，输入不被退休。已有Hold材料整体加入下一次合法整理，旧Hold分类不再阻止退休。
- 同一模型请求可对现有 facts/metadata 新增、修订、合并、覆盖、弱化、遗忘；不因旧origin优先级拒绝模型决定。本人显式隐私遗忘、身份权限及跨租户边界仍保护。完整快照版本防止迟到覆盖。
- 现有relations增加trust、impression、semantic_updated；亲近、信任及印象是模型的整体目标值。入站只记录真实互动和时间，不再逐消息机械加减分。共享整理可阅读参与人物合法历史关系；写入范围与当前bot隔离。
- 事实与关系整理不依赖naturalConversation开关，但继续遵守相应记忆/自我发展配置；这些可写开关在整理输入中明确给模型。
- 风格学习并入同次整理输入与事务；样本仍按原群隔离、需两位真人证据，不增加模型请求。取消每类结果固定取前4项。

## 持久化入口是否集中在35轮

并非所有持久化都在35轮，也不应把事务安全与真实执行记录延迟35轮。

| 类型 | 实际更新时机 | 本轮判断 |
|---|---|---|
| 摘要、核心笔记、模型事实/喜好、关系整体认知、批次表达学习 | 现有35轮整理事务；三小合一大保留 | 本轮修正认知权限、截断与清理顺序 |
| 本人明确记住/更正/忘记、管理员操作 | 实时显式操作 | 应保留即时生效；并发版本与隐私保护不能移走 |
| Journal、Work、发送确认、授权、未知外部效果 | 每次实际事件/执行事务 | 属于可靠性基础设施，不是等待摘要的认知记忆 |
| 真实互动时间、群成员、调度取消、约定执行状态 | 事件或执行时 | 应即时提供，不能用35轮旧快照覆盖 |
| 情绪、兴趣热度、主动话题、机器人显式表达 | 仍存在实时规则与现有整理更新 | 未借本次重构；不能声称都已改为模型35轮认知 |
| 工具经验、主动任务经历 | 实际工具/任务结算后，整理时进入基础视图 | 真实回执不等待35轮，模型认知不替代回执 |

已证实的问题是旧固定优先级限制语义事实修订、关系机械计分、样本早于学习清理、旧归档持有原图、模型产物被程序二次截断。本轮针对这些问题修复。其他入口仅按相关职责检查，未宣称完成全仓审计或统一所有人格机制。
