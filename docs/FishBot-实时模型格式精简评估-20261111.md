# FishBot 实时模型阅读格式评估

2026-11-11；依据当前代码及已有最终 Provider 采样。只读评估，不授权改写历史、删记忆或实施格式迁移。

## 判断标准

目标是保留全部有效语义，减少表示开销。自然语言并不天然比 JSON 省 Token；中文标题、重复解释和冗长句子也可能更贵。字符差只能作方向参考，需在相同事件的最终 HTTP 请求和实际 tokenizer/usage 上测量，不能把字符比例直接当 Token 比例。

需要区分：程序必须解析的结构、模型需要原样用于工具的结构，以及仅供模型阅读的资料投影。前两类不因“看起来像代码”而改成散文。已提交 Journal 的 role、顺序、序列化及媒体表示仍不可改；候选格式只能用于未来合法新增资料或合法重建边界。

## 按实际位置评估

| 资料 / 当前路径 | 格式判断 | 可讨论的紧凑表达 | 必须保留 |
|---|---|---|---|
| `context_foundation.read` 的 relations | 全量逐行重复字段名，有表示开销；零值行仍可能承载人物身份与接触时间 | 作用域分组后列出人物，统一说明列义；语义印象保留原文。自然语言与紧凑表格需对照测试 | subject、原 scope、亲近/信任及量纲、印象、时间、情绪有效期；不能删零值人物 |
| `memory_scope.summary_item` 的 protected_claims | 既有报告发现完整对象含 digest/sourceRefs/parents/visibility 等。不能笼统判这些字段全无用 | 模型阅读投影可用“说话人于何时提出何事，当前为提议/接受/撤销”等简洁句子；可操作 ID 单列 | 约定 ID、revision、参与者、状态、原会话、受众、真实说话者；工具后续需要的定位字段仍结构化。底层校验字段先核对用途 |
| facts 包装 | 同一 scope/人物的重复标签可共享，事实值不改写 | 一次人物头，下面逐条列字段与完整值 | 身份、事实与推断区分、有效状态、需要操作的键和版本 |
| expression_hints | 每条重复包装可考虑统一标题 | 表达原文＋适用情境；不把候选习惯当强制话术 | 原 scope、使用边界与真实表达；权重若影响模型判断应保留量义 |
| 当前事件与合并转发 | 扁平自然语言可以更易读，但删身份会造成严重歧义 | 一次外层转发说明；内部按顺序列作者、真实时间、正文，嵌套缩进 | 引用 ID/关系、节点顺序、原会话已知/未知、外层回复对象；不能猜来源。图片须保留节点关联与真实可见性 |
| readonly `set/remove` 增量 | **保留机器结构** | 仅可讨论说明文字是否重复；不能变成含糊的“最近有所变化” | 路径、操作、完整值、基底关系；后续增量必须能准确解释 |
| execution_experience / 任务回执 | 内容与状态职责不同，不能靠近似正文去重 | 对只读展示可分为“行动、时间、真实结果、尚未完成”，减少重复对象包裹 | 工具名、参数/结果关联、作用域、confirmed/unknown/partial/cancel 的区别；明确需要工具引用的 ID |
| 工具 Schema、Function Calling | **保留机器结构** | 只审查描述是否确有重复；不为格式收益删工具能力 | 名称、参数类型、required、枚举、调用 ID 和结果邻接 |
| 35 轮模型输出操作 | **保留 JSON**，用于持久化事务 | 使用指定条目的 create/replace/delete，未改条目省略 | 目标键、期望版本、完整替换值；禁止 append，不能自然语言猜测操作 |
| System / 人格及七轮提醒 | 稳定性比局部换词更重要 | 已有提醒语句简短；本项不改动 | 原角色设定、权限和 System 的独立稳定规则 |

## 已有真实证据与局限

此前生产固定 SDK 的只读 HTTP 验证：45 条物理消息、142529 字节、38792 输入 Token，缓存 35456、未命中 3336，0 图片。完整 execution_experience 仅一份，1947 字符；增量还原为当前有效值。这是隔离内存 Journal 的真实请求，未写生产 Journal，也不是最新一条自然 QQ 消息的 usage。

早期调查的 relations 24592 字符 / 117 行、89 行纯零值，是当时样本；不冒充当前全系统实时统计。它支持“重复字段名可能有格式收益”，不支持删除这 89 人。类似地，旧 protected_claims 约7000字符只能证明对象包装有研究价值，不能据此直接移除所有来源或操作引用。

本轮未为格式评估额外调用付费 Provider，没有新格式 Token 降幅实测；上述紧凑表达均属候选，不宣称已经省 Token 或保持质量。过去已修复的重复执行经验、只读缺基底问题沿用既有验收，不重新实施。

## 优先顺序建议（尚未执行）

优先评估关系/事实按身份分组后的表格或短文本，其次评估只读 claim 投影；保留原始底层数据和工具操作结构。每个候选在相同最终请求上核对全部事实、人物、时态、来源、受众和可操作引用，并确认真实 Token 与稳定前缀。仅少几个字符、增加引用跳转或解释负担的改动不值得迁移。

本轮第四项仅交付此评估。没有删除记忆、零值人物、来源语义或工具能力，也未实施新格式。
