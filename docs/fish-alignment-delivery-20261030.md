## 代码与职责

- `packages/contracts/fish-social-preset.ts`：同一份推荐预设供新建默认、管理台按钮和现有机器人应用使用。保留客户 Prompt、模型、URL、Owner、主动联系对象及预算；Key不参与预设传输。
- `packages/contracts/index.ts`：新增配置有类型、范围校验及兼容默认。旧配置明确关闭的值不被解析器偷偷打开；本次对测试 Bot 的应用单独走版本化 API。
- `adapters/astrbot/behavior.py`、`social.py`：跟进概率、单次图片决策、真实候选及图片消息段投递。
- `adapters/astrbot/runtime_care.py`：氛围缓存支持配置上限；已有双平台内存回收能力保留。
- `adapters/astrbot/meme_packs.py`：固定只读图包与各 Bot 排除列表；不加载全部图像字节，不运行新的常驻模型。
- `apps/control-api/src/meme-packs.ts`：归属校验、缩略图、每 Bot 版本化启停，写入串行且原子替换。普通用户不能替换公共文件或指定磁盘路径。
- `apps/web/src/meme-packs.tsx`：每页12张、延迟加载、来源链接及逐张启停；页面切换取消旧请求，迟到结果不回写。
- `scripts/import-fish-meme-pack.py`：固定归档导入工具，不在正式启动时运行；保留来源 manifest、原 LICENSE、归档 SHA256。原素材授权未指定，未将图片冒充 MIT。

安装后的157张总计85,554,968字节（约81.6MiB磁盘），不是同等常驻内存。运行时读取小索引、选中一张后读取该图；没有新增常驻 Web 服务、Embedding 或视觉模型。本次未进行新的完整内存压测，不给出虚构内存降幅。

## Plan vs Actual

计划是补齐已定位的社交默认、真实大肥鱼图包和可操作管理，并保留现有客户配置及隔离；这些修改均处于现有控制面/Adapter边界内，没有新增内核或引入任意 Python 插件。增加了“明确要表情包绕过随机概率”“安静时段抑制自动跟进”和每张图的并发版本控制，理由是避免配置对齐后出现不发图、夜间刷屏或旧操作覆盖新状态。

未将所有第三方可选功能机械开启：语音/唱歌/空间/签名需要另一套真实适配与凭据；自动视觉审图、完整个人风格建模、LivingMemory向量摘要尚未等价接入。原高播放作者未公开取得的内容与同模型主观效果对照仍未验收。因此本次可以证明具体功能和数值落地，不能据此宣称所有行为体验都已胜过原作者。
