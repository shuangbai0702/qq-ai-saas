# 自主模式运维接口与前端合并合同

当前合同对应 Linux 后端R33及Web R32（2026-11-02）。在 Windows 已完成的纸面界面中接入自主控制和管理员页面，主题及画布保持原实现；部署及验收证据见 [主动 AI 实施记录](proactive-ai-implementation-20261101.md)。

普通租户继续使用现有 `/v1/bots/:id/autonomous`、`/wake`、`/goals`，不能跨租户读取。管理员的新接口与普通 owned 路由分开，管理员身份不会扩大普通路由的所属权限。

普通租户 GET 已提供 `fresh`，与现有90秒健康有效期一致；`online` 只有在当前运行且报告有效时才为 true。`fresh=false` 显示“QQ 状态未知或已过期”，不能仅凭 online=false 断言用户已退出。页面分别呈现控制面模式和 pendingRuntime；过期采样不授予发送权限。后端在 claim、renew、决策提交及离线恢复处也核对采样，缺失或超出允许范围的未来时间不能作为在线凭据。

| 接口 | 作用 | 约束 |
| --- | --- | --- |
| `GET /v1/admin/autonomous?filter=attention&page=1` | 每页20个机器人，支持 attention / active / all；返回模式、epoch/runtime_epoch、脑状态、在线及数据新鲜度、wake、预算、错误、未确认动作标识 | 不返回健康对象、Key、人格、目标内容或聊天原文；QQ在线依据90秒采样有效期 |
| `GET /v1/admin/autonomous/:id/actions` | 按创建时间返回最多25个未确认动作，含 action/cycle ID、epoch、类型、目标、结果和原始效果回执 | 不含聊天正文或模型摘要；canResend=false；无实际回执时不能提供“重试发送”或“标记成功”按钮 |
| `POST /v1/admin/autonomous/:id/pause` | 暂停指定机器人的自主功能 | JSON为 expectedEpoch 和2–200字 reason；409表示状态变化，应重新读取；配置和管理员审计同事务提交 |

暂停复用既有模式切换：epoch前移、撤销未执行动作和wake、暂停活动目标，保留目标、回执、预算、QQ配置与全部账号数据。API不发消息，不重启协议或AI。返回pendingRuntime表示等待Agent确认，不应立即显示运行时已暂停。重复或并发提交至多一次成功，旧代次返回409。

结果unknown与“QQ离线”是两回事。在线实例每30秒最多查一次同一批原回执；切回被动后仍查证，不调用模型、不授予新动作。离线实例保留未决记录，等待用户真正重新登录；不得因核对回执拉起QQ。部分只读资料不可用不属于协议回执未知，不应挤占未确认效果队列。

页面需要分别显示QQ状态和自主脑状态：QQ在线时可显示自主休眠、等待预算或等待回执；不能把这些解释成QQ离线。显示模式时同时标出shadow/live；shadow只读执行与对外意图记录，不代表实际已发送。

管理员处理unknown的有效操作是查看原动作回执、等待自动查证、暂停该机器人的自主模式。没有后端证据时不允许人工将unknown改为confirmed，也不创建一个新action ID来重发旧效果。普通连续聊天仍沿原聊天路径处理并反馈外层；主动模式中的新执行任务由当前前台模型语义登记到同一交接箱，再交外层安排，任务工具不在此前执行。

界面入口为机器人一级“主动模式”（`/#/bots/:id/autonomous`）和“平台管理 → 自主任务”。普通面板10秒读取，管理员列表15秒、展开的原回执30秒读取；分页限制沿用后端，没有为每个机器人启动独立前端轮询。

常规配置与自主配置分别保存。自主面板的输入框回车和操作按钮不得提交外层常规配置表单；暂停使用服务器已保存的自主配置，保留其他未保存编辑，不能偷偷保存群白名单草稿。未保存自主配置时禁止唤醒及目标变更；离开本机器人内的其他页面前提示放弃草稿。网络结果不确定时重新读取权威状态，不自动重复暂停或发送动作。

管理员暂停需原因和 expectedEpoch，按钮同步防重入；页面退出后旧请求不能写入新页面。404/403 租户边界、未确认效果保留、单机器人暂停不影响同组成员均由真实隔离 API 浏览器测试覆盖。生产浏览器仅登录和 GET 核对，不对生产配置执行测试性保存或暂停。


R21起群白名单只有聊天配置中的`behavior.groupParticipationGroups`一份；主动层与既有群参与共用，仍交集服务群及现有准入。默认自主空闲判断600秒，自定义保留；这不是每10分钟强制发言，也不覆盖模型选择的更长休眠或每日预算。PG007保留既有目标、回执与用量，前移配置代次撤销旧许可。

R23起定向入站及前台结果在原生层保留至PG确认，普通群消息仅另留一个合并槽；policy的observedThrough只来自已提交观察，旧周期续期不能回退该水位。R24交接箱有pending时借既有policy响应触发下一次共享扫描，不等待普通30秒采样，不新增每QQ定时器。

R24原会话任务交付使用BotPipeline的请求回复许可：来源必须是本机实际Work交接并经PG接受的handoff，校验租户/机器人/epoch/generation/revision、目标ID及原会话，一个动作可正常分条。它只豁免主动打扰冷却及主动日额度，不豁免模式、在线、执行预算、末端校验或真实回执；不能换目标、目的地或action ID重发已确认/unknown结果。服务作者仍为0，不伪装主人。其他自主联系继续走原有联系人准入。

托管空@已停用上游独立waiter，其原引导不再作为user正文。公共管线传递实际mention事实并在system层说明处理要求，绑定原会话、使用原生锁内重载；不删除历史会话来掩盖此前污染。

当前生产存在request_token_budget保护性等待：当日剩余额度未必为0，但不足以容纳保守输入估计和最小输出。QQ仍可在线并正常前台聊天；不能把模式active等同于此刻有可执行自主预算。新版本真实QQ完整闭环需可用的原预算条件，尚未以重置用量或提高限制替代验收。R24灰度准备脚本尚未启动；不能把34项本地回归、13项Linux隔离PG测试等同实际QQ消息通过。

R25按用户新授权将dailyTokenBudget默认设0（无每日上限），仍保留单轮Token/模型/工具/动作/时间上限及实际用量计账。界面每日用量显示“不设每日上限”，不把0显示成余额耗尽；显式有限额度仍有效。此前R24的request_token_budget说明是历史状态，现生产0配置不再因每日剩余额度不足而拦截。23/24两个测试QQ明确保持passive，小双白保留用户已开启的active/live。小双白17:28真实外层模型选择休眠10分钟，本轮没有执行或发送回执，完整新版QQ闭环仍待验收。

R26仅调整外层自主选择与休眠语义：既有计划和自身意愿一并判断，单项完成或局部话题结束不代表全局休眠。疲劳仍为各scope的聊天节奏信息，不新增全局疲劳值。17:43部署，四QQ真实在线；首轮模型仍选择休眠，尚无新版自发行动回执，不能将提示词更新等同能力验收完成。Web保持R25。

R27自主配置独立提供fatigueEnabled=true、fatigueWindowMinutes=60，入口在一级主动模式的“自主活动与空闲记录”。仅向外层提供本机器人任务时长/次数、当前周期时长、距最后任务及真实聊天回复的空闲事实，无疲劳分数、次数上限或强制休息；无历史为null，仅检查不清零任务空闲，关闭开关不删除原始执行账本。与标准模式behavior.fatigueEnabled分开，标准模式的内部主动群消息仍可能受到旧窗口轮次硬门槛，本轮未改。主账号新一轮仍选择休眠，不能把配置上线当作自主行动验收已完成。


## R29 反馈和自主群候选边界

外层仅使用最新内层反馈及自身持续状态，不直接接入详细聊天记忆。`observation.latestFeedback` 为单条有界执行状态，不是第二份对话历史；普通事件不能覆盖它。决策前即时刷新、返回后核对版本，Work和末端执行再次验证；前台执行中延后自主决策。每轮最多增加前后两次本地runtime快照，无模型额外轮询、每QQ timer或独立常驻进程。

主动模式的群候选与普通消息触发分开：授权白名单群冷却到期后可自主开启话题，无需新群消息；静默/禁用、拒绝联系、服务群范围和末端投递校验仍生效。`mayInitiate` 表示可自主联系，不保证模型会选或发送成功；真正联系以实际动作与协议回执为准。群内At继续使用真实成员校验及原输出管线，目录和文字提及不能代替At回执。

后端R29不更改模式默认值及现有用户配置：23/24仍passive，小双白active/live；发布失败可仅关闭自主功能回到passive，不停止QQ、不清除目标和数据。R28/R29证据和剩余A–E/P5验收见实施记录。

R30只整理外层指令，未改变R29反馈、联系人或接口合同；18:38真实首轮仍选择休眠。不能把mode=active或mayInitiate=true展示为已联系成功，界面继续以实际动作及回执为依据。


## R31 自主调节与意图形成

新增fatigueRecoveryMinutes（默认30，5–240）、fatigueCapacityMinutes（默认20，1–240）、initiativeAfterIdleMinutes（默认30，5–1440），均为分钟。fatigueEnabled同时控制自主调节信息和连续空闲后的独立意图重评；不改变标准模式局部疲劳。负荷来自实际自主任务并随时间恢复，空闲积累行动倾向，连续休眠不会假装完成活动。具体公式、阈值和证据边界见实施记录。

GET周期条目新增orientation：本轮模型选择的动机、期望结果、engage/rest/wait、形成时间及当时调节状态。它是模型意图而非执行成功证明，页面须保留时间；不能将历史测量显示为实时疲劳值。新意图不授权联系人，不绕过权限，不代表实际已发QQ。意图期间模式或反馈变化仍使迟到规划失效。


## R32 / R33 更新

单周期Token默认100000，每日0为不限，原界面可收紧；其余六模型/八工具/两次对外动作/90秒及权限、回执和Guard保护保持。旧24000默认迁移，其他非默认额度保留。连续两次sleep后意图复评不再要求initiativePressure>=0.5；分数仍作为模型信息，不强迫联系或行动。R33只更新Node维护协调器，无QQ/Agent/AI/API重启，不更改自主配置epoch。

当前主机器人群白名单仅已脱敏账号，revision29已应用；候选私聊主人已脱敏账号保留。测试23/24仍被动。1750394406于R32部署前收到QQ会话失效通知，已按原五分钟机制清退至offline，未删会话/身份或自动重登。详细失败、复验、资源快照和Plan vs Actual见实施记录；本次修正不代表整体A–E/P95长稳验收全部完成。


## R37起的合同修正

自主配置不再接受capabilities字段；008迁移清除旧字段并撤销旧epoch。具体工具权限由原bot功能配置决定，外层仅接收真实能力目录。即时任务可由内层直接执行；长期目标使用既有交接箱，不能把已完成即时动作重复提交。前台完成反馈新增有界toolResults与真实读取evidence，不向外层复制群原文。activity新增lastProgressAt和idleSinceProgressSeconds，失败尝试保留负荷但不清空无进展时长。R39取消后的恢复间隔15秒，不修改用户自定义的120秒普通思考间隔。完整证据与尚未验收项见实施记录末尾。


## R40 / R42 当前额度与退出合同

R40默认24模型/32工具/500000 Token，每日0不限，上限64/128/2000000；保留非默认严格设置，主账号普通间隔120秒。R42将cycleSeconds改为连续无进展超时，默认90秒；真实模型/工具结果刷新计时，运行总时长超过该值不截断正常步骤。单工具30秒、短期效果许可、lease、身份、权限和unknown回执边界保留。

仅已提交的模型无动作决策写reason=sleep并使用用户普通间隔；预算/预检/并发打断yield15秒，异常backoff30秒。前台优先、离线挂起、测试23/24被动不变。续跑加载最新持久执行结果，不能遗忘未完成事项或重放未知操作。

旧登录会话expectedUin为空时，内部self任务从本成员绑定协议get_login_info读取实际身份；不写回或放宽账号校验，QQ操作前仍核对真实登录账号。签名/空间工具反馈保留受控detail；其他任意原始工具结果不传外层。真实发布、改签名成功仅以实际协议ACK确认，模型意图不作成功证明。R42生产发布状态与实际验收见实施记录，历史数值和结论均以最新节为准。

## R43 协作与选择合同

外层意愿及规划共享人物决策原则，按真实人格、兴趣、时间、关系、承诺、最近行动和实际成本形成下一项意图。未被点名不构成禁止主动交流；关系维护的价值不转化为强制发言，工具冷却只作用于该工具。明确当地时钟沿用项目UTC+08:00，不能据此推断联系人在线或作息。

内层反馈标注task身份/时间、stopReason和受控公开检索checkpoint。副作用已确认而计算中断记partial，不能重复发送；unknown仍禁止盲重试。恢复优先使用最近实际执行结果，未派发取消不遮挡它。外层不额外读取内层聊天原文、摘要或完整记忆；仍由内层按授权范围查询并反馈。意愿和规划各一次合同修复均计入现有预算，没有新增轮询、服务或每QQ常驻任务。
