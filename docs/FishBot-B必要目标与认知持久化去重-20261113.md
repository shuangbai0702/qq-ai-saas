# B必要目标与认知持久化去重

## 用户确认的范围

移除认知持久化/压缩基础区中重复的Goal、Action历史内容及对应自动更新入口；保留唯一权威Goal账本、原更新工具、Action和真实回执。每次真实主动激活仍将当前有效目标、必要进度和最新责任以简短B格式追加原主Journal末尾。已提交历史在合法检查点前保持不变。

“Goal14 / Action250”原为联合报告的权威账本统计，不是另有250个认知记忆条目；已从认知持久化清单移除。没有据这些统计删除生产账本。

## 实现

- `activity_context.necessary_goals` 保留真实目标id/revision/status/progress/updated_at、原始约束与nextIntention；当前未完/未知责任只留关联身份、状态、unfinished和未决效果标识，不复制已完成Action正文、参数或完整执行历史。连续两次投影幂等。
- `context_foundation.read` 不再从历史Action生成completed_experience。`execution_memory.context_projection` 不再向基础区自动写入已完成经历，自动资料只保留未确认责任，显式回顾工具仍返回完整真实账本。
- `bot_pipeline.experience_context` 不再自动注入已完成Action/历史决策，只保留unfinished、planned/executing/pending/partial/unknown/uncertain或未决效果；原Scope过滤和权限保持。
- `semantic_runtime._fresh_state` 只在合法退休重建中移除旧基础区的completed_experience/execution_experience副本；普通构建、重启和后台清理均不直接改写旧Journal。
- 摘要请求增加一句边界：不复制Goal/Action/ToolEffects条目或另建目标更新。没有替换主对话已提交System，没有新的目标工具、账本或计数器。

真实待续话题、社交联系计划、兴趣和执行回顾与权威Goal职责不同，本次没有把它们按名字当作重复Goal删除，也没有通过模糊关键词删事实或摘要正文。

## 压缩实际能更新的认知内容

| 类别 | 当前写入路径与含义 |
| --- | --- |
| 小摘要/大摘要 | memory_reflection原事务与合并；大摘要承接长期经历，不是任务状态账本 |
| 核心记忆 | update_core_note，基于真实来源和原版本 |
| 事实及更正 | apply_semantic_memory、原事实更新/修订权限与CAS |
| 人物关系 | affinity/trust/impression等语义修订，原证据和版本校验 |
| 兴趣 | memory_products的条目修订及companion_insights真实机器人表达证据 |
| 表达学习 | social.accept_summary_learning及memory_operations expression修订 |
| 情绪/心情 | companion_insights可按证据更新companion_emotion/mood；普通入站也有即时观察入口 |
| 真实待续话题 | motives按真实对话证据open/resolved/abandoned；不是Goal状态更新工具 |
| 互动反馈/表达强化 | effects核对真实人类反应，写dialogue_feedback/signals及reinforcement；沉默不视为拒绝 |
| 接话连续性 | conversation_continuity在同批合法检查点事务生成，禁止复制任务账本 |

反思、兴趣热度、约定及联系计划等另有事件/调度写入口；不能把“持久化存在”统称为“每35轮必更新”。每类是否提交取决于模块开关、真实证据、模型输出和版本校验，无变化不应强制写入。权威目标修订始终经原read_autonomous_goals/update_autonomous_goal，不由上述认知产品代替。
