# 本地纸面背景性能优化（2026-11-03）

性能优化与测试先在 Windows Web 纸面绘制模块完成；随后用户授权同步和 Git 推送，已独立发布 Linux 网页资源。不更改业务、机器人配置或其他前端布局。原文件副本保存在 `.local/paper-performance-20261103/`。

## 原因与修改

- `WallpaperPaint.draw()` 在笔触的 2.6 秒停留阶段也每帧重复合成；随后淡出会清空并重画整屏多层画布。现在停留阶段复用相同画面，变化时限制在当前与上一帧笔触的包围区域，保留过期笔触的擦除。首次绘制、素材准备及尺寸变化仍完整重画。
- `PaperSurface.step()` 为所有可见纸面重复写入相同 SVG 阴影、轮廓和位移属性，造成无效绘制失效。现在按最终属性字符串比较，仅提交变化值。
- `DryInk.draw()` 在没有笔迹时仍清空画布。现在空层直接返回，最后一条笔迹到期仍清空一次。

没有降低帧率、分辨率、笔刷密度、颜色或消退时长，也没有新增定时器、RAF、监听器和常驻缓存。

## 本地 A/B 结果

Chromium 无头浏览器，1440×1000，真实 React 登录页，三次相同轨迹：每次 90 次鼠标移动，然后等待 5.9 秒让笔触消退。主线程指标来自 CDP Performance，计数来自 Canvas/SVG 调用入口。

| 每轮均值 | 原版 | 优化后 | 变化 |
|---|---:|---:|---:|
| TaskDuration | 4761.7 ms | 3318.7 ms | -30.3% |
| ScriptDuration | 3314.0 ms | 2225.7 ms | -32.8% |
| SVG 属性写入 | 20020 | 581 | -97.1% |

优化后相同操作得到更多实际动画回调，因此不以绘图调用总数推断耗时。无头浏览器结果反映此设备与此场景，不能等同于所有显卡上的 GPU 或整机 CPU 降幅。未测完整生产会话或长时间资源曲线。

原始采样：`.local/paper-performance-20261103/before.json`、`after.json`；复现脚本 `measure.mjs`。
