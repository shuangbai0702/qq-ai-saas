## 本轮实际代码修正

1. Key已保存使用绿色状态；只表示密钥保存，不等于推理已经成功。
2. 管理页列出hug/laugh/thinking三张内置基础图，可预览、编辑使用场景、停用/启用；配置只写当前Bot覆盖文件，不改全局模板。自定义图仍最多5张，内置图不占此额度。QQ表情、聊天图片、普通图库仍分开。
3. 真正发送时：用户明确说“表情包”，QQ Face不会冒充图片发出；模型候选规则也明确区分。没有适合候选、冷却或额度限制时仍允许不发图，不能承诺每次强制投递。
4. 同一Bot表达使用范围：`local`当前群、`selected`指定群、`bot`全部群。只复用筛选后的表达提示，不混合原始学习样本、人物事实、私聊、表情收录；不同Bot始终分库。来源群或目标群停用的表达不能通过共享重新出现。
5. 用户后续授权调整新建默认：表达学习、语境接话、图片表情、跨群表达复用、分条开启；2%群插话、120秒跟进、800ms连发合并。主动总开关开启但对象列表为空，未配置已聊过的授权对象不会自动找陌生人。不能把这些设置称为复现GroupChatPlus的0.8跟进概率/完整疲劳规划。
6. 既有Bot明确保存的开关不被升级批量覆盖。新默认与旧配置兼容解析分开；旧无共享字段配置仍按群隔离，需要用户选择后保存应用。
