## 快速调整

### 如果动画太快
在 `:root` 中调整：
```css
--transition-normal: 500ms var(--ease-smooth); /* 改为 500ms */
```

### 如果渐变太亮
调整透明度：
```css
--accent: rgba(232, 93, 63, 0.9); /* 降低不透明度 */
```

### 如果想禁用某个动画
添加：
```css
.specific-element {
  animation: none !important;
}
```

## 常见问题

### Q: 看不到动画？
A: 检查浏览器是否支持 `backdrop-filter` 和 CSS 变量。

### Q: 性能卡顿？
A: 打开 GPU 加速，或在系统偏好中启用"减少动画"。

### Q: 颜色对比度不够？
A: 系统会自动检测 `prefers-contrast: high` 并加粗边框。

### Q: 如何回滚？
A: 
```bash
cp qq-ai-saas/apps/web/src/style.css.backup qq-ai-saas/apps/web/src/style.css
```
