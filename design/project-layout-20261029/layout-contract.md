# 本轮视觉边界

先完成邀请制、管理员邀请码管理、用户自助配置、模型发现及正式服务验证，再出图。设计依据是当前代码与浏览器真实回归，不将角色房间或聊天客户端当成托管平台。

两套各包含机器人列表和基本配置页：A 为蓝白侧栏工作台、卡片管理；B 为奶油珊瑚色横向导航、编辑式列表。共用大肥鱼/DeepSeek娘角色识别点，角色占约 10–15%，操作占主体。

必须对应的功能：自己的机器人、创建、QQ 连接、人格与 Prompt、URL/Key/模型 ID、自动模型列表、保存与生效版本、启停重启、群聊触发与白名单、记忆/表达学习/配图/主动聊天、日志。

邀请码管理仅管理员可见。普通用户页不展示其他租户、内部全局配置或 Master Key。示例模型使用 `gpt-5.6-luna`；Key 以已保存或遮罩显示。QQ 在线、AI 就绪、模型已配置分开表达，不把 Key 已保存当成推理验证。

设计图是静态视觉探索，示例状态不作为运行证据。最终 React 排版仍需确定性实现；不在本轮擅自替换正式管理台。
