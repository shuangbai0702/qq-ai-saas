两套均有蓝发鲸鱼娘、蓝白女仆装、鲸鳍耳、单鲸尾及白饭元素。使用上一轮本项目生成的大肥鱼图作为角色参考，缩小插画比例，让配置与管理按钮占主体。身份来源与社区二创边界沿用 [上一轮参考说明](../exploration-20261029/README.md)。品牌使用当前实际产品名“鱼栖”。

功能对应：自己的机器人、创建、QQ/AI/模型三类状态、人格与 System Prompt、自定义 URL、隐藏 Key、模型 ID、自动模型列表、群聊触发/白名单、记忆、表达学习、配图、主动聊天、保存/生效版本和日志入口。管理员邀请码管理在正式页面中实现，普通用户设计不展示管理员功能。

质量复核后做了三处独立修订：A 列表移除“QQ 官方登录”表述，把 AI 状态改为进程就绪；A 配置移除尚未实现的头像更换入口；B 配置明确“数据按机器人隔离保存，AI 运行时按组共享”。两套配置页的任意历史时间也改为版本说明。初稿与最终 v2 全部保留，无覆盖删除。

生成方式为内置 imagegen，提示词按执行轮次保存在 [主页面](prompts.json)、[配置及第一轮复核](prompts-config.json)、[最终文案复核](prompts-text-review.json)。最终四张图片的尺寸、字节数和 SHA-256 在 [asset-manifest.json](asset-manifest.json)。原始 PNG 已复制进工作区。

这是静态效果图，图中在线、版本、人数和账号均为示例。模型列表数量 11 来自本轮真实供应商 GET，但图中选中状态不作为推理或 QQ 实时证据；Key 从未写入图片或提示词。少量辅助导航/字数上限属于视觉占位，正式 React 实施时仍须逐项绑定实际路由、字段约束和状态。未用这两套图直接覆盖正式 UI。
