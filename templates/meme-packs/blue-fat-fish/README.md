# 蓝色大肥鱼表情包

Meme Manager 官方维护适配包，共 157 个动态 GIF，按聊天语义整理为 15 类。

## 安装

在 Meme Manager 资源广场的官方包区域安装「蓝色大肥鱼表情包」。

仓库：https://github.com/anka-afk/blue-fat-fish-meme-pack

发布版本：v1.0.0。适配与维护：anka-afk。

- 动画、画面尺寸和播放时长均按原文件保留，没有重新编码。
- manifest.json：包信息和分类说明；memes_data.json：兼容分类说明。
- memes/<category>/：分类图片；source_index.json：原文件映射、SHA-256 和动画信息。
- previews/：封面及全量双帧总览，编号与整理后文件名前缀对应。
